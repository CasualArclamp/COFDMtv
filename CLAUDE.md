# COFDMtv — notes for Claude

Desktop COFDMTV (pictures: Shredpix/Assempix; text: Rattlegram) and aicodix modem
datagrams, transmit and receive, in Rust, with DecDRM's look (`F:\DRM`). Read
`docs/DESIGN.md` first: the user's decisions, choices made, verification, milestones
(keep it current).

## Layout
- `crates/cofdmtv-core` — pure-Rust port of the aicodix C++ (0BSD): `coding/`, `dsp/`,
  `cofdmtv/` (modes, sync, meta/preamble, encoder, decoder, multiframe).
  `coding/tables.rs` is generated by `tools/gen_tables.py` from the C++ headers.
- `tools/cxx-reference` — builds the original programs from `reference/` (git-ignored
  clones of aicodix shredpix, assempix, rattlegram, modem, code, dsp, crs, disorders)
  with MSYS2 g++ (`/c/msys64/mingw64/bin`).
- `tests/fixtures` — signals made by the originals (see its README).
- DecDRM (`F:\DRM`) is the model for the GUI and audio code: reuse its patterns
  (eframe 0.36 `logic`/`ui`, `egui::Panel`, snapshot polling, cpal + rtrb streams).

## Commands
- Tests: `cargo test --release -p cofdmtv-core` (loopback at every rate, compat fixtures).
- Cross-check against the originals (local only, needs the reference build):
  `bash tools/cxx-reference/build.sh`, then `bash scripts/xcheck.sh` (88 checks) and
  `bash scripts/sensitivity.sh [TRIALS] [multipath]` (also build aicodix/disorders into
  `target/cxx-reference`).
- WAV encode/decode with the reference programs' command lines:
  `cargo run --release -p cofdmtv-core --example wavcodec -- encode|decode|split …`.

## Conventions
- DSP in `f32` (`dsp::Cplx` = `Complex32`), like the originals; cite the C++ file an
  algorithm follows in doc comments.
- Keep the receivers equivalent to the originals (same sample positions, same rate-0
  shortcuts in the list decoder); behaviour changes need a cross-check run.
- User is strong in DSP, newer to Rust: explain non-obvious Rust idioms briefly.
- Git identity is repo-local (Arclamp, GitHub no-reply address); commit per milestone.
  Never commit `reference/`, recordings or secrets. On Windows, stop own helper processes
  by PID, never by image name.
